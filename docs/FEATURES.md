# 功能与统一统计格式

## App 功能

- 三套角色主题：M5、城市探索、静谧书库。M5 使用标准 Android 动态壁纸；另外两套为静态原图。
- 息屏、背屏仅提供素材预览和导出：三主题 PNG，M5 另有循环 GIF。App 不调用厂商专属设置或启动指定背屏。
- 标准桌面组件显示额度、统计窗口、每日 Token、数据截至时间、可用重置卡数与最近到期时间。不同额度区间切换颜色和人物表情；演示预览与真实统计分开。
- 云同步由用户填写 GitHub 仓库或 HTTPS 原始 JSON 地址，私有源需只读授权；APK 不包含预配账号、仓库或令牌。
- APK 内置自动拉取实现，并提供电脑端工具与提示词离线包。手机只读取统计 JSON，不执行下载的脚本；电脑工具在用户自己的主机运行。
- 每轮同步完成后目标约 10 分钟再次检查，开机和升级后可恢复已启用的任务；网络、省电与系统调度可能延迟。手动强制同步跳过版本缓存。

## 通用 JSON

`schemaVersion: 1`，通用来源 `source: "agent_usage"`。`provider` 是实际 Agent / 服务的名称，例如 `Codex`、`Claude` 或其他名称，长度 1–32。旧 `source: "codex_app_server"` 格式保留兼容，用于可信的 Codex 本地接口导出。

所有 `observedAt` 表示实际读取统计的 Unix 整秒，不能用任务启动时间冒充读取成功时间。使用 `chartMode: "live"`；演示值不能当作真实统计上传。

| 字段 | 类型与含义 |
| --- | --- |
| `schemaVersion` | 固定整数 `1`。 |
| `source` | 通用输出固定为 `agent_usage`。 |
| `provider` | 非空字符串，1–32 字符，标明实际来源。 |
| `observedAt` | 实际读取时间的 Unix 整秒。 |
| `chartMode` | 真实统计固定为 `live`。 |
| `quota` | 额度摘要，见下表。 |
| `daily` | 上游每日 Token 统计，见下表。 |
| `resetCards` | 可用重置卡摘要，见下表。 |

不要求提供 `summary` 或 `rateLimits`。不要为凑字段复制原始接口响应。上传前用 `desktop/snapshot_schema.py` 校验；发布脚本也会校验输入。

### quota

| 字段 | 含义 |
| --- | --- |
| `remaining` | 额度剩余百分比，`0..100` 数值；未知为 `null`。不能将绝对 Token 数或余额直接填到百分比。 |
| `resetsAt` | 对应额度窗口的下一次重置 Unix 秒；未知为 `null`。 |
| `window` | `weekly`、`daily`、`monthly`、`other` 或 `unknown`，保留上游额度窗口。 |
| `observedAt` | 本次读取该统计的 Unix 整秒。 |
| `source` | 通用格式固定为 `agent_report`。 |

只可使用可信来源明确报告的剩余值或可验证的同一窗口已用百分比。不同窗口不能混用；没有可读上游时输出未知，不根据对话长度、模型估算或账户套餐推断额度。

### daily

| 字段 | 含义 |
| --- | --- |
| `buckets` | `[{"date":"YYYY-MM-DD","tokens":非负整数}]`，未知为 `null`。仅有明确统计的日期才进入数组。 |
| `dateSemantics` | 固定字符串 `upstream dates unchanged; missing dates unknown`。 |
| `observedAt` | 本次读取时间的 Unix 整秒。 |
| `source` | 通用格式固定为 `agent_report`。 |

`date` 保持上游日期含义；不要自行按另一时区拆天。缺失日期不是 `0`，不得自动补齐。只有上游明确表示某日统计为零时，才可写入 `tokens: 0`。只有来源明确说明整个期间没有用量时，才可把空数组视为已知无统计；无法读取时使用 `null`。

### resetCards

| 字段 | 含义 |
| --- | --- |
| `availableCount` | 可用数量，`0..2147483647` 整数；未知为 `null`。 |
| `expiresAt` | 可用卡中最早已知期限的 Unix 秒；未知或不适用为 `null`。 |
| `expiryStatus` | `unknown`、`none`、`no_expiry`、`earliest` 或 `partial`。 |
| `observedAt` | 实际读取时间的 Unix 整秒。 |
| `source` | 通用格式固定为 `agent_report`。 |

| 情况 | 正确表示 |
| --- | --- |
| 没有可信的重置卡统计 | 数量、期限为 `null`，状态 `unknown`。 |
| 明确无可用卡 | 数量为 `0`，期限 `null`，状态 `none`。 |
| 全部可用卡详情完整且明确无期限 | 状态 `no_expiry`，期限 `null`。 |
| 全部详情完整且存在已知期限 | 状态 `earliest`，写入最早期限。 |
| 详情不完整但能确认一部分期限 | 状态 `partial`，仅写入已知最早期限；没有已知期限时保持 `unknown`。 |

付费余额、积分或 Token 余额不等于重置卡。数量使用来源的权威统计，不能用可能截断的详情列表长度代替。最近到期不是全部卡的统一截止；当前界面按北京时间显示期限。过期后等待新统计，不自动把全部卡归零。

## 同步与错误处理

电脑先在私有位置生成 JSON，完整写入临时文件并原子替换，校验通过后才发布到用户指定的统计仓库。Git 写入使用本机凭据；遇到未解决冲突不强推。

手机保存数据源后自动拉取；有版本缓存时可条件请求，未变化保留当前统计。网络、授权、HTTP 或数据格式错误时保留最后成功数据，状态页报告失败。每次保存配置都会先清除旧源缓存和统计，避免混用不同账户数据；主题选择保留。重新保存同一私有源也须重新输入只读令牌。

数据只包含白名单统计：不上传聊天、提示词、邮箱、账户 ID、卡 ID、详细卡描述、登录文件、API 密钥或原始响应。定时任务提示词本身在 [TXT 文件](../prompts/scheduled-usage-task.txt)，创建计划任务仍需用户明确授权。
