# v0.29.0 验证记录

验证日期：2026-10-08。最低 Android 11（API 30），目标 API 35。本记录区分源码设计、主机测试、构建和真机结果。

## 主机检查

- Python 用量导出、统一 JSON、Git 发布、HTTPS 拉取及构建隔离测试共 76 项，通过。其中代码仓库拉取的 6 项真实 bare Git 测试覆盖快进、脏工作区、分歧及不执行 hooks/内容过滤器。
- JVM 148 项断言通过：额度策略 26、重置卡 42、数据源/授权头 39、GIF 独立解码 11、组件位图预算 30。
- 源码已移除小米私有息屏入口、固定副屏编号和外部 Intent 测试导出入口。
- 离线工具包采用明确文件白名单，APK 资源以 SHA-256 清单校验；源码、工具包与解包 APK/Dex 字符串经 Gitleaks v8.30.1 扫描，未发现凭据；不包含 SDK、签名私钥、真实统计或登录文件。

## 真机检查

测试设备为小米 17 Pro Max，Android 16 / 澎湃 OS 3。使用独立 `local.codex.wallpapers.qa` 包及独立私有 Provider；生产包数据不作为测试输入。

独立 QA runner 的 48 项离线真机断言通过：统一 JSON 有效与非法状态、旧版兼容、换源清统计与 ETag、Keystore/AAD 加密、两个屏幕预算的标准 RemoteViews 实际 inflate 与动画帧、静态回退渲染、实际场景 GIF 编码和 Android Movie 解码。

两个 GIF 均为 30 帧、每帧 120ms、3.6 秒无限循环；电脑 Pillow 独立解码也确认帧数、尺寸和可见运动。五张新版 App 内截图已从 QA 包生成并人工查看，使用合成演示数据，授权输入框为空；说明见 [截图记录](SCREENSHOTS.md)。

电脑端 `pull_snapshot.py` 已从本公开仓库匿名拉取合成示例并通过校验。随后手机 USB 断开，手机真实 HTTPS 拉取与正式 APK 覆盖安装尚未完成；不据此声称手机已收到新统计。尚未配置用户个人数据源。

## 公开交付

Release APK 的包名为 `local.codex.wallpapers`，版本 29 / 0.29-portable，`debuggable=false`。安装签名校验与下载 SHA-256 结果放在 Release 的 `SHA256SUMS.txt`，不分发签名私钥。

公开仓库只包含新项目的源码、必要素材、说明、演示截图、提示词及测试；个人统计须放到用户自行配置的数据仓库。

## 尚未覆盖

- 其他品牌、Android 11–15、第三方桌面和低内存实体设备尚未逐一实测。
- 组件预览及 `RemoteViews.apply` 不等于所有系统桌面宿主已验收；宿主可以限制动画和刷新。
- PNG/GIF 导出不等于系统已应用息屏或背屏，具体导入方式及 GIF 支持由手机决定。
- GitLab/Gitea 私有实例、组织 SSO、所有服务的真实只读令牌未逐一端到端验证。
- 电脑未开机、上游不可读、系统省电导致的延迟不能由统一 JSON 协议消除。仓库提供提示词，不会自行建立用户计划任务。
