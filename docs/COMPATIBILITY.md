# Android 兼容性

源码检查基线：v0.29.0，2026-10-08。基础功能面向 Android 11+，不再依赖小米息屏设置入口或指定背屏显示编号。使用公共接口扩大兼容范围，不等于已经在所有 Android 手机验收。

## 系统要求

最低 Android 11（API 30），目标 API 35。Android 10 及以下不可安装。本项目不按手机制造商或 ROM 名称限制启动；安装门槛、系统提供的能力与实际机型验证是三件不同的事。

## 功能边界

| 功能 | 实现方式 | 使用条件 |
| --- | --- | --- |
| 主题与素材预览 | Android View / Canvas | 不要求小米系统；不同屏幕比例、字体缩放需要实际检查。 |
| PNG / GIF 导出 | 相册文件导出 | 三主题可导出 PNG；M5 的息屏 / 背屏素材可导出 GIF，另外两主题为静态。第三方相册的展示方式可能不同。 |
| 静态桌面 / 锁屏壁纸 | Android 标准壁纸接口 | 系统需允许修改对应壁纸；设备管理策略或厂商限制可能阻止操作。 |
| M5 动态壁纸 | Android WallpaperService 与系统选择器 | 系统需支持动态壁纸；独立动态锁屏、桌面与锁屏的应用范围由系统决定。 |
| 息屏 / 背屏 | 仅预览和导出素材 | App 不接管系统息屏或副屏。你须在手机自带设置中选择素材；不支持自定义图片 / GIF 的机型无法通过本 App 增加该能力。没有背屏也可预览和导出。 |
| 用量桌面组件 | Android AppWidget / RemoteViews | 桌面需支持 Android 组件。尺寸、添加确认、动画和后台刷新受桌面宿主及系统限制。 |
| 云同步 | HTTPS、JobScheduler、Android Keystore | 不依赖小米接口。需要用户配置数据源；后台约 10 分钟检查是调度目标，省电或网络可能延迟。 |
| 可选手机用量页读取 | 用户开启的无障碍服务 | 只针对其支持的页面；页面布局变化会影响识别。其他 Agent 数据建议通过统一 JSON 同步。云同步不要求该授权。 |

GIF 是普通图片素材；导出成功不表示已设置为系统息屏、背屏或锁屏。系统只接受静态图时，使用 PNG。GIF 导出尺寸与壁纸原图不同，详见界面的实际预览。

## 组件位图与动画

Android 对一次组件更新的位图总内存有限制，官方预算与屏幕像素面积相关，约为 `屏幕宽 × 屏幕高 × 4 × 1.5` 字节。见 [AppWidgetManager.updateAppWidget](https://developer.android.com/reference/android/appwidget/AppWidgetManager#updateAppWidget(int,%20android.widget.RemoteViews))。

当前实现按屏幕预算调整底图、动画帧尺寸与帧数，并预留余量；预算不足或宿主拒绝动画更新时，尝试较小的静态组件。不同桌面可能有额外限制，低分辨率下可读性与动画效果仍需真机检查。此策略避免固定大帧占用，不能代替其他品牌和桌面的验收。

## 数据源与服务兼容性

手机支持 GitHub 仓库模式及 HTTPS 原始 JSON 地址。GitHub 可填写用户 / 组织、仓库、分支 / 提交与文件路径；其他服务需要提供最终返回原始 JSON 的 HTTPS 地址。

支持的授权头为无认证、`Authorization: Bearer …`、`PRIVATE-TOKEN: …`、`Authorization: token …`。服务端必须支持其中一种方式；网页登录、Cookie、交互式验证码及会重定向到其他地址的 URL 不适用。App 拒绝重定向，避免把授权转发给非预期地址。

通用 `agent_usage` 统计与旧 `codex_app_server` 格式兼容。显示的额度窗口需保持来源含义；不同服务的 Token 统计和限额不能直接视为同一种额度。

## 日期与刷新

传输时间统一使用 Unix 秒。每天的 `date` 保持上游原日期，不擅自转换时区或把缺失日期补成零。当前重置卡有效期按北京时间（`Asia/Shanghai`）显示；组件中的展示时间以界面标识为准。

手机读到旧数据或暂时无网络时会保留最后成功结果，因此“已同步”不是实时额度保证。期限已到但未取得新重置卡统计时显示待更新，不把全部卡自动清零。

## 验证范围

历史版本曾在小米 17 Pro Max、Android 16 / 澎湃 OS 3 上验证；这不能替代 v0.29.0 或其他品牌的验收。当前版本实际执行的测试、构建、安装与演示截图结果统一记录在 [验证记录](VERIFICATION.md)。

其他品牌、Android 11–15、低分辨率设备、第三方桌面和各厂商的系统息屏 / 背屏选择方式均需要独立实测。仓库截图证明对应 App 界面可以渲染，不代表系统已应用素材或桌面宿主已经验收。
